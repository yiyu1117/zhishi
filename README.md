# 知时（Zhishi）

一个 Android 防沉迷**自控**工具：给装在自己手机里的"闸门"。打开上瘾应用前强迫你先决定用多久，到点强制送回桌面，超用进入冷却期，每天还有总量上限。纯本地、无账号、无联网，开源侧载分发。

> 它防的是"不自律的自己"，不是孩子（不做家长管理，也没有任何绕不过去的锁——你自己握着钥匙，这正是设计的一部分）。

## 功能

- **分组管理**：应用按分组施加不同强度的管控——
  - **默认组**：未分组的用户应用自动落入，机制全关（装完即用、不被误管），配置可改；
  - **黑名单组**：彻底禁用，打开即全屏"禁止使用"；
  - **白名单组**：完全豁免（地图、支付这类关键时刻打不开会误事的）；
  - **自建组**：自由创建/删除，每组内嵌一份完整配置。
- **开屏时间选择**：打开守护应用先弹全屏浮层——6 个快选档位（默认 5/10/15/20/30/60 分钟）+ 假数字键盘自定义（默认上限 120 分钟）；浮层出现 5 秒后按钮才可点，破除"习惯性盲点过"。浮层上显示今日剩余额度。
- **会话与宽限期**：选定后前台计时；退后台/息屏计时暂停，宽限期内（默认 2 分钟）回来继续；宽限耗尽判**中途放弃**，进入比到期冷却更短的**放弃冷却**（默认 5 分钟）。
- **到期与延时**：时间耗尽弹"时间已到"，确定按钮 5 秒保护，点击后送回桌面并进入**到期冷却**（默认 8 分钟）；冷却期可**延时使用**一次（默认 2 分钟，按钮 10 秒保护，结束前 30 秒 Toast 预告），未用则带入冷却期。冷却倒计时仅在你不处于该应用内时推进。
- **每日限额**：-1 禁用 / 0 不限 / N 分钟，按自然日累计、零点重置；实际到期取"所选时长剩余"与"当日剩余额度"中较小者；额度用尽立即中断并当天禁用。
- **提醒**：会话中周期报告已用时间（默认每 10 分钟）；距到期 5/2/1 分钟（刻度可增删）提醒；撞点只弹一条，剩余提醒优先。
- **六项机制逐组开关**：开屏时间选择、周期用量提示、剩余时间提醒、延时使用、到期冷却、放弃冷却——默认全关，按组定制强度；开启时弹影响范围警告。
- **自律锁**（默认关）：仅每天指定时段可改配置，防住深夜不自律的自己。
- **双检测模式**：无障碍服务（默认，毫秒级拦截）与 UsageStats 轮询（兼容模式，允许 1–2 秒延迟），设置中切换。
- **重启恢复**：所有会话、冷却与每日记账在手机重启后恢复原状。

## 工作原理

```
前台检测（二选一）        守护状态机（纯 Kotlin，每应用一个实例）      系统动作
┌─────────────────┐      ┌──────────────────────────────┐      ┌─────────────┐
│ 无障碍服务        │ ──▶  │ 待选择 → 会话中 → 宽限期/到期  │ ──▶  │ 全屏拦截浮层  │
│ (窗口状态变化)    │      │ → 延时 → 冷却 → 额度用尽/禁用  │      │ Toast 提醒   │
│ UsageStats 轮询  │      │ 注入时钟源，效果输出驱动动作    │      │ 送回桌面     │
└─────────────────┘      └──────────────────────────────┘      └─────────────┘
```

- **前台检测**（`docs/adr/0001`）：无障碍服务监听窗口状态变化，毫秒级感知应用切换，是默认模式；部分设备上无障碍可能被 ROM 限制或你不想授权，可切换到兼容模式——前台服务轮询使用统计，允许 1–2 秒延迟（拦截前目标应用可能短暂闪现）。
- **守护状态机**（`:core` 模块，纯 Kotlin）：所有时间语义集中在一个注入假时钟即可单测的状态机里——宽限期边界、冷却推进与冻结、延时一次与带入、min 到期、零点重置全部有单元测试覆盖。
- **拦截浮层**：系统悬浮窗（`TYPE_APPLICATION_OVERLAY`）全屏覆盖目标应用；窗口不带焦点，**系统手势永远可用**——任何配置都不会把你锁在手机外面；本 APP、桌面、系统 UI、输入法被固定排除，也不会出现在应用选择器里。
- **存储**：分组/配置/自律锁/检测模式存键值存储（DataStore）；"应用 × 自然日"使用记账与会话/冷却状态存 SQLite——重启后恢复原状。全部纯本地。

## 权限说明

| 权限 | 用途 | 为什么需要 |
| --- | --- | --- |
| 无障碍服务 | 监听窗口切换 | 毫秒级感知你打开了守护应用，浮层才能盖住它 |
| 显示在其他应用上层 | 拦截浮层 | 全屏覆盖守护应用的选择/冷却/禁止提示 |
| 使用情况访问（兼容模式） | 轮询前台应用 | 无障碍不可用时的替代检测 |
| 常驻通知（兼容模式） | 前台服务 | 维持轮询服务存活 |
| 电池优化豁免（兼容模式） | 服务保活 | 部分设备会杀后台轮询 |
| 查询所有应用 | 应用选择器 | 列出可管理的应用（含可切换显示的系统应用） |
| 开机自启 | 恢复守护 | 重启后服务/检测自动恢复 |

**本应用不申请网络权限**：没有任何联网代码，不可能上传你的使用数据。

## 编译

要求：JDK 17+，Android SDK（API 36）。

```bash
./gradlew.bat :app:assembleDebug    # 调试包
./gradlew.bat :app:assembleRelease  # 签名 release 包（keystore 随仓库分发，见下）
./gradlew.bat :core:test            # 状态机单元测试
```

产物在 `app/build/outputs/apk/`。`local.properties` 里配好 `sdk.dir`（或设 `ANDROID_HOME`）。

### 发布与签名

`keystore/***REMOVED***.keystore`（口令 `***REMOVED***`，alias `zhishi`）随仓库分发——这是有意为之：开源侧载项目没有需要保密的发布身份，随仓库的 keystore 保证任何人都能构建出**可安装**的 release 包。介意者可删除并用自己的 keystore 替换（改 `app/build.gradle.kts` 的 `signingConfigs.release`）。

## 安装使用

1. 构建 release APK 侧载安装（或从 Release 页下载）；系统要求 Android 8.0（API 26）及以上；
2. 打开「知时」，按引导开启**无障碍服务**与**悬浮窗权限**；
3. 把想管的应用加入分组（或新建分组定制机制与参数）；
4. 打开一个守护应用试试闸门。
