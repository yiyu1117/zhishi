# 07 — Toast 提醒体系

**What to build:** Toast 发射器承担三类提醒：周期用量提示（默认每 10 分钟报告本会话累计使用）；剩余提醒刻度列表（默认 5/2/1 分钟，可在设置中增删刻度），跟随实际到期点（所选时长剩余与当日剩余额度中较小者）；延时时已有 30 秒预告（05 已做，此处仅回归）。两类提醒撞在同一刻时剩余提醒优先、周期提示顺延，绝不同时弹两条。仅在会话前台进行期间弹出，后台暂停期间不弹。

**Blocked by:** 06 — 每日限额与使用记账

**Status:** ready-for-agent

- [ ] 会话进行中每 10 分钟弹"已使用 X 分钟"（本会话累计）
- [ ] 距实际到期剩 5/2/1 分钟时弹"剩余 X 分钟"
- [ ] 提醒刻度可在设置中增删
- [ ] 撞点时只弹一条：剩余提醒优先，周期提示顺延
- [ ] 后台暂停期间两类提醒均不弹
- [ ] 单测覆盖撞点顺延与刻度到点计算
