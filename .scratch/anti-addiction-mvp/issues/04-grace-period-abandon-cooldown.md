# 04 — 宽限期与放弃冷却

**What to build:** 会话中退后台/息屏（视同退后台）启动宽限期（默认 2 分钟，可配）：期内回到应用则从剩余时间继续；宽限期耗尽判为中途放弃，本次会话作废并进入放弃冷却（默认 5 分钟，可配），冷却浮层显示"X 分钟后可打开"。落地冷却推进规则：冷却倒计时仅在用户不处于该应用前台时推进——停留在冷却浮层期间冻结，离开后推进。冷却结束后打开应用回到时间选择浮层（新会话）。假时钟单测覆盖全部边界。

**Blocked by:** 03 — 开屏时间选择会话与到期（状态机核心）

**Status:** ready-for-agent

- [x] 退后台 1 分钟内回来，剩余时间与离开前一致
- [x] 宽限期耗尽后回来直接进入放弃冷却浮层，不回到时间选择
- [x] 放弃冷却默认 5 分钟；浮层显示剩余等待
- [x] 停留冷却浮层期间倒计时冻结，离开应用后推进
- [x] 息屏视同退后台，计入宽限期
- [x] 冷却结束后打开应用弹时间选择浮层（新会话）
- [x] 宽限期时长与放弃冷却时长可在配置中修改
- [x] 假时钟单测覆盖宽限期边界与冷却推进规则
