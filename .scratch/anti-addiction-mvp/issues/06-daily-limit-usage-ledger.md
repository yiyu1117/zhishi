# 06 — 每日限额与使用记账

**What to build:** 数据库按"应用 × 自然日"累计前台使用时间；每分组新增每日限额配置（-1 禁用 / 0 不限 / N 分钟）。拦截浮层显示"今日剩余 X 分钟"；会话实际到期 = min(所选时长剩余, 当日剩余额度)，剩余提醒刻度同样跟随此到期点。当日累计达限额即立即中断当前会话，弹"今日 N 分钟已用完，零点重置"浮层（确定 5 秒保护、送回桌面、无延时），当天不可再用。自然日切换自动重置。黑名单组重构为"每日限额 = -1"的配置取值，行为与之前完全一致。杀进程重启后记账与会话/冷却状态恢复。

**Blocked by:** 05 — 到期冷却与延时使用

**Status:** ready-for-agent

- [x] 限额 N 分钟的组内应用当日累计达 N 即被中断并禁用到零点
- [x] 时间选择浮层显示今日剩余额度；所选时长超过剩余时按剩余到期
- [x] 额度用尽浮层确定后送回桌面，无延时可用
- [x] 限额 -1 = 禁用；0 = 不限；黑名单组行为与重构前一致
- [x] 零点后额度重置，可重新选时使用
- [x] 剩余提醒刻度按 min 到期点触发（额度先尽时相对额度耗尽点）
- [x] 重启后当日累计与会话/冷却状态完整恢复
- [x] 假时钟单测覆盖 min 到期与零点重置
