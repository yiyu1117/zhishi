# 02 — 分组模型与应用选择器

**What to build:** 分组数据模型与持久化，以及分组管理界面。可自由创建/删除自建分组；默认组兜底（未分组的用户应用自动属于它）不可删除；黑名单组、白名单组默认为空且不可删除。应用选择器默认隐藏系统应用（可切换显示）；固定排除（本 APP、系统桌面、系统 UI、输入法）永不出现在选择器中。移动语义：把应用加入新分组即从原分组移出。六项机制开关随分组存储，默认全关；本票仅接线黑名单语义：黑名单组内应用打开即弹"禁止使用"浮层（无时间选择、无会话），其余机制开关存而不接。

**Blocked by:** 01 — 工程骨架 + 无障碍检测 + 最小拦截闭环

**Status:** ready-for-agent

- [ ] 可创建/删除自建分组；默认组、黑名单组、白名单组不可删除
- [ ] 未分组的用户应用自动出现在默认组
- [ ] 选择器默认隐藏系统应用，切换开关后可选；固定排除应用永不出现
- [ ] 应用加入新分组后自动从原分组消失（每应用恰属一组）
- [ ] 黑名单组内应用打开即被"禁止使用"浮层覆盖
- [ ] 白名单组、机制全关的自建组与默认组的应用不被拦截
- [ ] 删除分组时其应用回归默认组
