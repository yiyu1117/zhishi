# 03 — 开屏时间选择会话与到期（状态机核心）

**What to build:** 守护状态机（纯 Kotlin 域层，注入时钟源）：待选择 / 会话中 / 时间耗尽三个状态及迁移，用假时钟单元测试建立本仓库的测试范式。时间选择浮层：6 个快选按钮（默认档位 5/10/15/20/30/60 分钟，已确认）、浮层出现 5 秒后按钮才可点击、自定义时间假数字键盘（上限默认 120 分钟）。开启"开屏时间选择"机制的守护组应用生效：选定时长后正常使用并前台计时；退到后台计时暂停、回来继续（本票为临时无限宽限，04 引入上限）；时间耗尽弹"时间已到"浮层，确定按钮 5 秒保护，点击后主动送回桌面。机制关闭的分组应用不受影响。

**Blocked by:** 02 — 分组模型与应用选择器

**Status:** ready-for-agent

- [ ] 开启机制的守护组应用打开即弹时间选择浮层
- [ ] 快选按钮 5 秒内不可点，之后按档位选定并开始会话
- [ ] 自定义键盘可输入，超上限（120 分钟）被拒绝
- [ ] 前台使用至时间耗尽，弹"时间已到"浮层
- [ ] 确定按钮 5 秒保护；点击后送回桌面
- [ ] 切后台计时暂停，回到应用从剩余时间继续
- [ ] 假时钟单测覆盖：选定→计时→到时→确定的迁移与按钮保护窗口
- [ ] 机制关闭的分组应用不被时间选择拦截
