# 01 — 工程骨架 + 无障碍检测 + 最小拦截闭环

**What to build:** 从零初始化 Android 工程（Kotlin + Jetpack Compose，minSdk 26，target 最新稳定 API，不申请网络权限）。实现前台检测的无障碍 provider（监听窗口状态变化），内置一个硬编码的示例守护应用；检测到它进入前台时，弹出全屏拦截浮层（显示应用名 + "回桌面"按钮），点击后关闭浮层并执行全局回桌面动作。打开本 APP 时检测无障碍权限，未开启则显示引导页并可跳转系统设置。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 开启无障碍权限后，打开示例守护应用，拦截浮层即时覆盖全屏
- [ ] 浮层"回桌面"按钮点击后回到桌面，浮层消失
- [ ] 未开无障碍权限时打开本 APP 显示引导页，可跳转系统设置
- [ ] 非守护应用前台时不出现任何浮层
- [ ] 手机重启后无障碍服务自动恢复，拦截仍生效
